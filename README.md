# Airport Management System

## Overview

A comprehensive database-driven system designed to manage airline operations, including passengers, flights, bookings, employees, and airports.

The project focuses mainly on database design and implementation, with a simple web-based interface for management.

## Project Type

Database System + Web Interface

## Features

* Manage passengers and their details
* Manage flights and available seats
* Booking system with automatic seat updates
* Search functionality across tables
* Activity logging system
* Reports and activity tracking

## Database Components

* Tables:

  * Passengers
  * Flights
  * Bookings
  * Employees
  * Airports
  * ActivityLogs

* Advanced Database Features:

  * Stored Procedures (Add, Delete, Search, etc.)
  * Functions (statistics and counts)
  * Triggers (automatic logging)
  * Indexes (performance optimization)
  * Package (modular database operations)

## Technologies Used

* SQL (Oracle)
* PHP
* HTML
* CSS

## Interface

The system includes a simple web interface with pages such as:

* Passengers
* Flights
* Booking
* Search
* Reports

## Notes

* This project focuses heavily on backend/database logic.
* The frontend is simple and designed for demonstration purposes.
* ERD and schema were part of the project but are not currently available.

## Purpose

This project demonstrates advanced database concepts and real-world system design for airline management.

## How to Use

1. Import the database scripts into Oracle DB
2. Run the PHP project on a local server (e.g., XAMPP)
3. Connect the database to the application
